## 🚀 Core Capabilities

The suite is divided into distinct operational modules, each addressing a critical aspect of modern extraction combat. This modular approach ensures you only load what you need, minimizing interference with your system's core processes.

### 🎯 TARGET ACQUISITION SYSTEM (TAS)
- **Advanced ESP Framework**: Visualize hostile presence and critical loot through a dynamic rendering engine. This isn't just a simple overlay; the TAS uses a **prioritization algorithm** to filter and highlight entities based on threat level, distance, and line-of-sight (LOS) integrity.
- **Intelligent Trajectory Projection (ITP)**: Forget static aiming. The ITP module calculates enemy movement vectors and environmental physics, providing an **adaptive aim-assist** that feels natural and organic, reducing visible "snapping" and ensuring smoother adjustments.
- **Occlusion Aware Rendering**: See through walls, but understand the context. The system subtly alters transparency based on the thickness of the obstruction, giving you a **spatial awareness advantage** without cluttering your view with unrealistic, blocky outlines.

### ⚡ OPERATIONAL TEMPO MODULATOR (OTM)
- **Time Perception Control**: Adjust the flow of the game to your operational rhythm. This includes a **speed sub-system** that modifies movement parameters in a controlled manner, allowing for rapid repositioning or tactical retreats—all within a framework designed to avoid triggering standard server anti-cheat heuristics (use at your own discretion).
- **Resource Cascade Optimizer**: The **financial layer** of the suite. This tool streamlines in-game currency gain by automating complex but repetitive trading loops and identifying high-yield extraction routes, effectively acting as a **market arbitrage advisor** for your virtual ledger.

### 🛠️ UTILITY OVERLAY INTERFACE (UOI)
- **Dynamic Radar Cartography**: A minimalistic, opaque map generator that updates in real-time, plotting known NPC spawns, interactive objects, and player-created sounds. It’s the **intelligence dashboard** that keeps your main viewfinder clean.
- **Configurable Macro Engine**: Create complex, multi-step input sequences for actions like looting or healing. The engine allows for human-like random delays to maintain a natural profile.

## 🧩 Architecture & Technical Insights

The core engine is written in a high-performance compiled language to minimize CPU footprint. It uses a **hook-based abstraction layer** that allows for rapid updates when the game client receives patches. The UI is built on a lightweight web-view framework, allowing for genuine CSS/JS customization of your HUD—this is why we refer to it as a **'Custom Operating System'** for your game screen.

To get started, you don't need to "install" anything in the traditional sense. Instead, you will need to run the primary launcher executable which will inject the selected modules into the target process. This process is streamlined:

1.  **Extract** the archive to a clean, dedicated directory.
2.  **Run** the `WRAITHMARK_Launcher.exe` as an administrator.
3.  **Select** your desired modules from the splash UI.
4.  **Launch** the game and press your designated activation key (`F9` by default) to toggle the overlay.
